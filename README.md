# Li-Motors — концепт сайта

Демо-концепт редизайна сайта li-motors.ru (продажа и сервис Lixiang / Li Auto), All That Jazz Studio.

- `index.html` — русская версия, `index-en.html` — английская, `blog.html` — журнал.
- Тексты и фото статей журнала взяты с li-motors.ru, статьи открываются на li-motors.ru.
- Часть фотографий подобрана/сгенерирована для макета. Цены, контакты и форма — демонстрационные, форма заявки никуда не отправляется.
- Страницы закрыты от поисковиков (noindex).
